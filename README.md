# Machine Vision Project

Project scaffold for the Machine Vision major task (see provided PDF for full specification).

Structure created:
- src/ : Python source
- data/ : datasets (not checked in)
- notebooks/ : exploration and analysis notebooks
- models/ : trained model outputs and checkpoints
- tests/ : unit tests
- docs/ : project documents
- scripts/ : helper/run scripts

Quick start
1. Create a virtual environment and install requirements from `requirements.txt`.
2. Run the project with `scripts\run.ps1` (Windows PowerShell) or run `python -m src.main`.

See `docs/PROJECT_SPEC.md` for more details (placeholder).
